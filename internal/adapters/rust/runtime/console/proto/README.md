# Tokio Console protocol bindings

These files are generated from the official `tokio-rs/console` tag `console-api-v0.9.0`, matching `console-subscriber` 0.5.x. They are committed so building Sen does not require Protobuf tooling.

Do not edit generated Go files by hand. Update them together with Sen's accepted `console-subscriber` version because the console protocol does not promise cross-version compatibility.
